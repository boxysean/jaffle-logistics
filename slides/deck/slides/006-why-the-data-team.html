WHY THE DATA TEAM

Modeling data for BI was analytics engineering. Modeling it for AI is context engineering.
THE TEAM THAT OWNS THE DATA
The team that owns the data now owns how good the company's AI gets.

Model quality became answer quality. If the definition of "on time" is wrong in the model, every agent that reads it is wrong — and confidently so.

  • Analytics engineering modelled data so a person could read it. Context engineering models that same data so an agent can read it.
  • Tests, documented definitions and contracts were good practice for BI. For AI they are essential.
