The warehouse, the semantic layer and the retrieval are built. The agent on top is what the data now makes possible.
Click through the six steps. A question arrives; the warehouse's tools answer over MCP, never a guessed number. There are two sources of truth, kept visibly apart: the semantic layer owns the number (10 governed metrics, the definition belongs to the business) and the knowledge base owns the cause (vector search over 7 document sources: transcripts, CRM notes, incidents, dispatch). The answer is the number and the cause: 56.60% on time, and the 14-16 January storm. Then the evidence: lineage back to the source system, and 340 tests per build. Then the action: a person decides, or an agent acts, for example routing a complaint, raising the service-level risk before the customer feels it, or stopping a dispatch when a driver's certification has lapsed. Be clear that this loop is a design, not a running system. Adapted from the context-layer pattern, not copied.
