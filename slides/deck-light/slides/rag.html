RAG IS NOW A COMMODITY

Every warehouse ships the primitives in SQL
PARSE
documents to text
▶
CHUNK
text to passages
▶
EMBED
passages to vectors
▶
SEARCH
vectors to answers
Snowflake, Databricks, BigQuery: one function each.
The functions are commodity.
The pipeline between them is the engineering.
Parse, chunk, embed, search: Snowflake, Databricks and BigQuery each ship these as SQL functions (AI_PARSE_DOCUMENT, AI_EMBED, VECTOR_COSINE_SIMILARITY on Snowflake; ai_parse_document, ai_query, Vector Search on Databricks; ML.PROCESS_DOCUMENT, ML.GENERATE_EMBEDDING, VECTOR_SEARCH on BigQuery). Documented 2026-09-07. The function stakes are table stakes. What decides quality is the pipeline between the calls: what gets chunked, what is hashed so unchanged text is not paid for twice, how each row keeps a citation, how batches are governed. The per-warehouse table is in the appendix.
