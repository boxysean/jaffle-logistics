SAME CRAFT. A DIFFERENT READER.

From analytics engineer to context engineer
BEFORE
A PERSON READS
The deliverable is an answer
A chart. A dashboard. It answers once, then it is a dead end.
NOW
AN AGENT READS
The deliverable is the meaning
Definitions, grain, caveats, lineage. It answers every question downstream.
For a decade the work product was an answer: a chart, a dashboard. Now it is the meaning, because that is what an agent reads, and an agent cannot ask a clarifying question. A dashboard answers once; meaning answers every question downstream of it. The models are the same. The audience is not. The job changes when the reader changes; the craft does not. And you are already most of the way there: you write meaning down for a living, you own the semantic layer, you already run the gate an agent needs (tests, contracts, freshness, lineage), and you write in the one language both readers share, versioned code.
